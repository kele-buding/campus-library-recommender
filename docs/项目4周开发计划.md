## 一、项目与技术基线概览

### 1.1 已确认技术栈

| 层级 | 技术选型 | 说明 |
| :--- | :--- | :--- |
| **后端框架** | Java（JDK 21 字节码，兼容 OpenJDK 27）+ Spring Boot 3.4 | 模块化单体，事务边界清晰，便于并发控制 |
| **数据访问层** | MyBatis-Plus 3.5 + Flyway | 单表 CRUD 零 SQL，复杂查询与行锁 SQL 可控；Flyway 统一管理建表脚本 |

## 二、开发流程模型与 4 周总流程

### 2.1 软件开发流程模型：混合模式（前期瀑布 + 编码期轻量敏捷）

- **前期（已完成）采用瀑布式文档基线**：需求规格、概要设计、详细设计（`DU-01` ~ `DU-10`）及 12 张数据库表结构已明确，避免编码期需求漂移。
- **编码与交付期（未来 4 周）采用轻量敏捷迭代（Scrum-lite / 增量交付）**：
  - 以 **1 周为 1 个 Sprint**，共 4 个 Sprint；
  - **高风险前置**：第 1 周攻克数据库并发事务与四角色权限，第 2 周打通华为云 FunctionGraph 与 OBS 联调，避免临近截止才集成翻车；
  - **每周产出可运行、可演示的软件增量**：第 2 周末即可达到“全部基础功能可演示”的保底交付状态，第 3 周完成拔尖进阶功能，第 4 周专攻并发测试与高质量交付材料。

### 2.3 团队协作与工程规范

1. **Git 分支协作**：
   - `main` 为每周验收后的稳定分支；所有开发从 `main` 切出 `feat/<DU编号>-<简述>` 分支，自测通过后提 Pull Request，经至少 1 位组员 Review 后合并。
2. **数据库变更纪律**：
   - 任何表结构或索引调整必须通过新增 Flyway 脚本（`V2__xxx.sql`）完成，禁止私自修改已执行的 `V1__init_schema.sql`。
3. **云安全与免费额度红线**：
   - 华为云 AK/SK、回调 Token、数据库密码全部通过 `.env` / 环境变量读取；开发期默认开启 `HUAWEI_CLOUD_MOCK=true`，仅在联调与演示时切换真实云端，并开启应用层预算上限控制，确保全程 **0 付费**。
4. **轻量同步节奏**：
   - **每周一（15 分钟）**：对齐本周任务与接口字段（对照《详细设计文档》）；
   - **每周四（15 分钟）**：同步阻塞点与云联调进度；
   - **每周日（20 分钟）**：在真实 PostgreSQL 环境下做本周里程碑 Demo，并顺手记录本周 1 条真实 AI 辅助开发记录。
